# Changelog

All notable changes to Threadline are documented here.

## 0.1.0 — 2026-07-14

### Product

- Added the Threadline brand, marketing narrative, and causal-thread product preview.
- Added a responsive Command Center with live briefing, pulse, graph, change risk, and agent activity.
- Added Incident Room replay with synchronized metrics, timeline, evidence inspection, and safe demo mitigation.
- Added service map, change intelligence, agent mission control, incident history, and reporting surfaces.
- Added a global keyboard-first command menu.

### Platform

- Added Next.js App Router, React, TypeScript strict mode, and Tailwind CSS v4.
- Added deterministic Meridian Market domain fixtures and pure filtering/graph utilities.
- Added PWA manifest, conservative service worker, offline route, metadata, sitemap, robots, and generated social image.
- Added security headers, CI, unit tests, contribution guidance, security policy, and architecture documentation.

### Accessibility

- Added semantic landmarks, skip navigation, visible focus, reduced motion, chart labels, non-color state cues, and graph alternatives.
